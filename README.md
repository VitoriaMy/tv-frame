## 🛠️ 项目文档：基于蓝牙监听的隐藏式激光电视伺服定位伸缩架 (DIY Open-Source Project)

本项目通过微控制器（建议使用 ESP32）主动监听激光电视的蓝牙（Bluetooth）连接状态。当电视开机并发出蓝牙信号时，系统驱动主平台精准滑出，同步带动前滑盖向后收纳至固定后盖下方；当电视关机或蓝牙断开时，主平台回到原点，前滑盖同步复位关闭，恢复隐藏式整体外观。

本版本重点从传统“电动推杆 + 限位停机”升级为“伺服精准定位 + 双段式上盖同步联动”，适用于超窄型激光电视柜模块、隐藏式展示平台与需要良好外观整合的智能家居设备。

---

## 一、项目目标与应用场景

### 1.1 项目目标
- 实现激光电视平台的自动滑出与收纳。
- 利用蓝牙连接状态作为设备开关机的间接判断信号。
- 使用伺服定位或带编码器驱动机构，实现可重复、可调整的精准工作位置。
- 通过双段式上盖设计，提升外观整合度与使用体验。
- 提供具备基本安全保护、可 DIY 落地的硬件与控制逻辑方案。

### 1.2 适用场景
- 客厅隐藏式激光电视柜。
- 超窄型激光电视柜模块。
- 智能家居设备联动展示机构。
- 需要平稳伸缩与外观遮蔽的展示平台或收纳模块。

### 1.3 项目特点
- 支持主平台精准控制最终伸出位置。
- 上盖采用双段式结构，外观更接近成品家具模块。
- 前滑盖与主平台可做同步联动，动作流畅。
- 支持状态机控制，便于后续扩展手动控制、遥控、Wi‑Fi 联动等功能。
- 可按需求选择“单电机 + 机械联动”或“双驱动协同控制”方案。

## 二、设备尺寸、承重与摆放条件

本方案以激光电视 / 投影设备尺寸 **510 × 270 × 144 mm**、重量 **7.9 kg** 为基准进行机构设计。平台、导轨、驱动与上盖结构需同时满足摆放空间、承重、安全裕量与散热避让等条件。

### 2.1 已知设备条件
- 设备尺寸：**510 × 270 × 144 mm**
- 设备重量：**7.9 kg**

### 2.2 平台尺寸建议
为了满足设备摆放、防滑、装配与散热需求，不建议将平台做成仅刚好容纳设备的尺寸。

建议平台有效摆放尺寸至少为：
- **长度 ≥ 560 mm**
- **宽度 ≥ 320 mm**

较稳妥的实作建议：
- **平台面板尺寸：560～600 mm × 320～360 mm**

### 2.3 承重设计建议
设备本体重量虽为 **7.9 kg**，但结构设计不应只按静态重量选型，还需考虑：
- 平台自重
- 固定支架与防滑垫
- 线材与拖链负载
- 启停过程中的动态惯性
- 偏载、长期磨损与安全裕量

因此建议：
- **平台、导轨与驱动整体按 ≥ 15 kg 等效负载进行设计**
- 若追求更高耐久性与稳定性，可按 **15～20 kg 级**结构规格选型

### 2.4 摆放与散热建议
- 设备四周应预留至少 **20～30 mm** 的安装与散热间隙。
- 出风口与进风口方向不得被上盖、侧板或联动结构遮挡。
- 若柜体较封闭，建议加开散热孔或增加辅助风扇。
- 线材、插头与转接头的高度和弯折半径应纳入总高度设计。

### 2.5 结构避让要求
- 前滑盖收入固定后盖下方时，不得侵占设备本体摆放空间。
- 平台运动层、滑盖收纳层与设备空间应尽量分层设计。
- 设备放置位置应尽量靠近平台受力中心，避免前端悬臂过长。
- 平台伸出后仍需具备足够的抗下沉、抗偏摆与抗扭转能力。

## 三、上盖结构设计（双段式同步滑盖）

本方案的上盖不再采用传统翻盖，而采用更适合超窄型柜体的双段式结构：

- **固定后盖（Rear Fixed Cover）**：靠墙安装，不参与运动。
- **前滑盖（Front Sliding Cover）**：待机时与固定后盖共同形成完整顶面；开启时沿导向机构向后滑动，收纳至固定后盖下方。
- **主平台（Projector Platform）**：承载激光电视本体，向前精准滑出到工作位置。

### 3.1 动作逻辑
本版本采用**上盖打开与平台滑出同步操作**的思路：

- 主平台开始向前运动时，前滑盖同步向后移动。
- 前滑盖逐步收入固定后盖下方，平台逐步向外伸出。
- 收回时，平台向内回位，前滑盖同步向前复位闭合。

### 3.2 设计优点
- 靠墙侧不需翻转空间。
- 外观完整，待机状态更像一体式家具模块。
- 开启过程更有产品感，视觉上为“平台滑出、盖板消失”。
- 适合超窄型柜体与低高度模块设计。

### 3.3 设计注意事项
- 固定后盖下方需预留前滑盖的收纳高度与导向机构空间。
- 前滑盖应具备独立导向结构，避免偏摆或卡滞。
- 前滑盖关闭末端建议加装磁吸、定位销或缓冲胶垫。
- 平台与滑盖的导向层应尽量分离，不建议共用单一简化滑槽。
- 应预留线束活动空间，避免与平台或滑盖干涉。

### 4.1 工作原理概述
1. 激光电视开机后，蓝牙进入可连接或已连接状态。
2. ESP32 检测到目标蓝牙设备状态变化。
3. 控制板触发主平台向前移动。
4. 平台移动同时，前滑盖通过联动机构同步向后滑入固定后盖下方。
5. 平台到达目标工作位置后减速停止。
6. 关机时，平台回原点，前滑盖同步关闭复位。

## 七、控制流程说明

```text
[系统上电]
    ↓
[初始化 IO / 读取原点状态 / 进行必要回零]
    ↓
[读取蓝牙连接状态]
    ↓
┌──────────────────────────────────────┐
│ 已连接且当前平台未展开？             │──是──► [平台向前滑出]
└──────────────────┬───────────────────┘                │
                   │否                                   ▼
                   │                         [前滑盖同步向后收纳]
                   │                                     │
                   │                                     ▼
                   │                         [到达工作位置后停止]
                   ▼
┌──────────────────────────────────────┐
│ 已断线且当前平台已展开？             │──是──► [平台向内回位]
└──────────────────┬───────────────────┘                │
                   │否                                   ▼
                   ▼                         [前滑盖同步向前闭合]
               [持续轮询]                               │
                                                        ▼
                                                   [待机完成]
```

### 7.1 状态逻辑
- **蓝牙已连接 + 平台未展开** → 平台向工作位置移动，前滑盖同步打开。
- **蓝牙已断开 + 平台已展开** → 平台回原点，前滑盖同步关闭。
- **其余状态** → 保持当前状态，避免重复驱动。

### 7.2 同步联动建议
可按实际结构选择以下策略：
1. **单电机 + 机械反向联动（推荐）**：主平台由单一驱动器控制，前滑盖通过同步带、连杆或拉索实现天然同步。
2. **双驱动协同控制**：主平台与前滑盖各自驱动，但需额外处理同步误差与故障保护。
3. **分段联动**：前滑盖在前段动作期间同步开启，完全打开后平台继续前进。

## 八、核心控制源代码（ESP32 状态机示意）

```cpp
// 示意用途：伺服定位 + 同步滑盖架构
// 实际控制方式需按驱动器通信方式、位置回授方式与机构比例调整

enum SystemState {
  IDLE_CLOSED,
  OPENING_AND_EXTENDING,
  IDLE_OPEN,
  RETRACTING_AND_CLOSING,
  ERROR_STATE
};

SystemState state = IDLE_CLOSED;

bool bluetoothConnected = false;
bool platformAtHome = true;
bool platformAtWork = false;

long homePosition = 0;
long workPosition = 29000;   // 例如 290 mm 对应的编码器计数
long currentPosition = 0;

void setup() {
  // 初始化 GPIO、蓝牙、驱动器、原点开关等
}

void loop() {
  bluetoothConnected = readBluetoothState();
  currentPosition = readPlatformPosition();

  switch (state) {
    case IDLE_CLOSED:
      if (bluetoothConnected) {
        startMoveTo(workPosition);
        state = OPENING_AND_EXTENDING;
      }
      break;

    case OPENING_AND_EXTENDING:
      // 前滑盖由联动机构同步动作
      if (isAtPosition(workPosition)) {
        stopPlatform();
        state = IDLE_OPEN;
      }
      break;

    case IDLE_OPEN:
      if (!bluetoothConnected) {
        startMoveTo(homePosition);
        state = RETRACTING_AND_CLOSING;
      }
      break;

    case RETRACTING_AND_CLOSING:
      // 前滑盖由联动机构同步复位
      if (isAtPosition(homePosition)) {
        stopPlatform();
        state = IDLE_CLOSED;
      }
      break;

    case ERROR_STATE:
      stopPlatform();
      break;
  }
}

bool readBluetoothState() {
  return false;
}

long readPlatformPosition() {
  return 0;
}

bool isAtPosition(long target) {
  return abs(readPlatformPosition() - target) < 20;
}

void startMoveTo(long targetPosition) {
  // 发送位置命令给主驱动器
}

void stopPlatform() {
  // 停止主平台
}
```

### 8.1 源代码说明
- 以**状态机**取代阻塞式 `while`，便于扩展与保护。
- 主平台只需要控制目标位置；前滑盖由联动机构同步完成动作。
- `workPosition` 可按柜体深度、投影需求与机构尺寸调整。
- 建议加入超时、堵转、越界、回零失败等错误保护。

### 8.2 当前版本建议补强项
- 动作超时保护。
- 原点校准流程。
- 故障检测（如平台未到位、滑盖卡滞）。
- 手动维修模式。
- 断电重启后的位置恢复策略。

## 九、关键配置步骤：绑定电视蓝牙 MAC

为防止误判或误连到其他设备，可通过蓝牙扫描或绑定策略锁定目标电视设备。

### 9.1 配置流程
1. **获取电视 MAC 地址**  
   打开电视蓝牙，使用蓝牙扫描 App 或串口工具记录电视的 MAC 地址。  
   例如：`94:E6:63:AB:CD:EF`

2. **设置扫描或连接策略**  
   若使用 ESP32 原生蓝牙，可按 MAC 地址过滤目标设备。

3. **测试设备状态变化**  
   验证电视开机、待机或关机时，蓝牙状态是否能稳定被检测。

### 9.2 注意事项
- 不同品牌电视的蓝牙广播策略不同，实际测试非常重要。
- 若电视蓝牙在待机时仍持续可见，需搭配其他条件做判断。
- 若需更高可靠性，可考虑 Wi‑Fi、红外、CEC 或继电器信号作为辅助。

## 十、安装与结构设计建议

### 10.1 机构安装重点
- 主平台导轨需确保全程平行，避免偏摆与卡点。
- 前滑盖导向需轻量、低摩擦，并保证不与主平台干涉。
- 固定后盖下方必须预留前滑盖的收纳空间。
- 平台重心与驱动力方向应尽量同轴，以提升寿命与稳定性。
- 平台面板尺寸应满足 **510 × 270 mm** 设备本体摆放需求，并预留散热与固定边距。

### 10.2 盖板设计建议
- 上盖由两部分组成：**后盖固定，前盖滑入后盖下方**。
- 前滑盖打开与平台滑出采用**同步操作**。
- 关闭末端建议加入磁吸、阻尼或缓冲结构，避免撞击异响。
- 可在前滑盖底部加尼龙滑块、滚轮或低摩擦条，提升手感与耐久性。

### 10.3 安全建议
- 建议加入保险丝、急停开关或过流保护。
- 高电流线材请选择足够线径，避免压降与发热。
- 柜体内需保留散热空间与维修通道。
- 初次测试请先空载、低速、短行程验证。

## 十一、调试流程建议

### 11.1 单元测试顺序
1. 单独测试控制板供电是否正常。
2. 单独测试蓝牙状态检测是否正确。
3. 单独测试主平台驱动是否可精准往返指定位置。
4. 单独测试前滑盖联动是否顺畅、无卡滞。
5. 测试平台滑出与前滑盖同步动作是否一致。
6. 最后再整合蓝牙判断与自动控制流程。

### 11.2 常见故障排查
| 现象 | 可能原因 | 建议处理 |
|---|---|---|
| 蓝牙已连接但平台不动作 | 蓝牙判断逻辑错误 / GPIO 设置异常 | 先确认 ESP32 是否正确读取目标状态 |
| 平台定位不准 | 编码器参数错误 / 传动打滑 | 重新校准位置对应与传动张力 |
| 前滑盖动作不顺 | 导向偏摆 / 摩擦过大 / 同步带过松 | 检查导向平行度与联动张力 |
| 平台回位正常但盖板闭合不齐 | 滑盖末端定位不足 | 增加磁吸、定位销或可调挡块 |
| ESP32 重启 | 驱动启停造成压降干扰 | 加强供电、分离电源、增加滤波电容 |
