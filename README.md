## 🛠️ 專案文檔：基於藍牙監聽的隱藏式激光電視電動伸縮架 (DIY Open-Source Project)

本專案透過微控制器（Arduino / ESP32）主動監聽激光電視的藍牙（Bluetooth）連線狀態。當電視開機並發出藍牙訊號時，系統驅動電動推桿自動展開抽屜；當電視關機或藍牙斷開時，抽屜自動收回，達到隱藏式安裝與自動聯動的效果。

---

## 一、專案目標與應用場景

### 1.1 專案目標
- 實現激光電視抽屜/支架的自動展開與收納。
- 利用藍牙連線狀態作為設備開關機的間接判斷訊號。
- 以低成本、可 DIY 的方式完成整體控制系統。
- 提供具備基本安全保護的硬體與控制邏輯方案。

### 1.2 適用場景
- 客廳隱藏式激光電視櫃。
- 智慧家居設備聯動展示機構。
- 需要自動升降/伸縮的展示平台或收納模組。

### 1.3 專案特點
- 成本相對低，零件容易取得。
- 可使用 Arduino Nano / UNO 或 ESP32 實現。
- 支援機械限位保護，降低卡死與過衝風險。
- 可進一步擴充為遙控、手動按鍵、Wi‑Fi 聯動等版本。

```text
       └───────────────────────────┬────────────────────────────┘
                                   │
                                   │ 無線藍牙訊號

 │   │  HC-05 藍牙   ├──────────────────►│ Arduino Nano  │        │
 │   │  (掃描連線)   │                   │  (控制核心)   │        │

 │   └───────────────┘                    └───────┬───────┘       │
 │                                                │               │
 └────────────────────────────────────────────────┼───────────────┘
                                                  ▼
                     ======================================
                     [限位開關A] ◄── 電動推桿 / 滑軌 ──► [限位開關B]
                     ======================================
```

### 2.1 工作原理概述
1. 激光電視開機後，藍牙進入可連線或已連線狀態。
2. HC-05 或 ESP32 偵測到目標藍牙設備狀態變化。
3. 控制板根據狀態判斷是否需要展開或收回。
4. 馬達驅動模組驅動電動推桿動作。
5. 到達行程末端時，由限位開關觸發停止。

### 3.1 選型建議
- **Arduino Nano**：體積小、成本低、開發簡單，適合基礎方案。
- **ESP32**：整合藍牙與 Wi‑Fi，後續擴充性較強。
- **L298N**：適合入門與小功率負載；若推桿電流偏大，建議改用更高效率驅動器或繼電器/H 橋方案。
- **電動推桿**：務必確認推力、速度、行程、負載與安裝尺寸符合實際櫃體設計。

## 四、硬體接線定義 (Wiring Definition)

| 起始元件與引腳 | 目標元件與引腳 | 線路類型 | 備註說明 |
|---|---|---|---|
| HC-05 (STATE) | Arduino (D7) | 訊號線 | 監聽藍牙連線狀態（HIGH=已連，LOW=斷開）。 |
| Arduino (D5) | L298N (IN1) | 數位控制 | 控制推桿前進（展開）。 |
| Arduino (D6) | L298N (IN2) | 數位控制 | 控制推桿後退（收起）。 |
| 限位開關 A (OUT) | Arduino (D2) | 訊號線 | 展開極限位置感應（建議 INPUT_PULLUP）。 |
| 限位開關 B (OUT) | Arduino (D3) | 訊號線 | 收起極限位置感應（建議 INPUT_PULLUP）。 |
| L298N (OUT1/OUT2) | 電動推桿 (正/負極) | 動力線 | 驅動推桿正反轉。 |
| 12V 電源 (+/-) | L298N 電源輸入 | 動力電源 | 為驅動板與推桿供電。 |
| 降壓模組輸出 5V | Arduino / HC-05 | 邏輯電源 | 避免直接使用不穩定供電。 |
| Arduino GND | L298N GND / HC-05 GND | 共地 | 所有控制模組必須共地。 |

### 4.1 接線注意事項
- 所有模組必須 **共地（GND 共通）**，否則控制訊號可能異常。
- 若 HC-05 為 3.3V 邏輯等級，需確認與控制板的 IO 電平相容性。
- 馬達啟動瞬間電流較大，建議控制電源與動力電源分開穩壓。
- 限位開關建議加入軟體去抖或 RC 濾波，提升穩定性。

## 五、控制流程說明

```text
[系統上電]
    ↓
[初始化 IO / 停止馬達]
    ↓
[讀取藍牙連線狀態]
    ↓
┌──────────────────────────────┐
│ 已連線且目前未展開？         │──是──► [執行展開] ─► [碰到展開限位] ─► [停止馬達]
└──────────────┬───────────────┘
               │否
               ▼
┌──────────────────────────────┐
│ 已斷線且目前已展開？         │──是──► [執行收回] ─► [碰到收回限位] ─► [停止馬達]
└──────────────┬───────────────┘
               │否
               ▼
           [持續輪詢]
```

### 5.1 狀態邏輯
- **藍牙已連線 + 支架未展開** → 執行展開。
- **藍牙已斷線 + 支架已展開** → 執行收回。
- **其餘狀態** → 不動作，避免重複驅動。

## 六、核心控制原始碼 (Arduino C++)

```cpp
/**
 * 激光電視藍牙聯動伸縮架控制程式
 * 適用平台：Arduino Nano / UNO
 * 驅動晶片：L298N
 */

// 定義 L298N 馬達驅動引腳
const int motorPin1 = 5;  // 控制推桿前進
const int motorPin2 = 6;  // 控制推桿後退

// 定義限位開關引腳
const int limitOpen = 2;   // 展開到位的極限開關
const int limitClose = 3;  // 收起到位的極限開關

// 定義藍牙狀態引腳 (HC-05 的 STATE 引腳)
const int bluetoothStatePin = 7;

bool isExtended = false; // 紀錄目前推桿是否已展開

void setup() {
  pinMode(motorPin1, OUTPUT);
  pinMode(motorPin2, OUTPUT);
  pinMode(limitOpen, INPUT_PULLUP);
  pinMode(limitClose, INPUT_PULLUP);
  pinMode(bluetoothStatePin, INPUT);

  stopMotor();
}

void loop() {
  int bluetoothConnected = digitalRead(bluetoothStatePin);

  if (bluetoothConnected == HIGH && !isExtended) {
    extendShelf();
  } else if (bluetoothConnected == LOW && isExtended) {
    retractShelf();
  }
}

void extendShelf() {
  while (digitalRead(limitOpen) == HIGH) {
    digitalWrite(motorPin1, HIGH);
    digitalWrite(motorPin2, LOW);
  }
  stopMotor();
  isExtended = true;
}

void retractShelf() {
  while (digitalRead(limitClose) == HIGH) {
    digitalWrite(motorPin1, LOW);
    digitalWrite(motorPin2, HIGH);
  }
  stopMotor();
  isExtended = false;
}

void stopMotor() {
  digitalWrite(motorPin1, LOW);
  digitalWrite(motorPin2, LOW);
}
```

### 6.1 原始碼說明
- `bluetoothStatePin` 用於判斷藍牙是否已與目標設備建立連線。
- `isExtended` 避免重複觸發相同動作。
- `extendShelf()` 與 `retractShelf()` 使用 while 持續執行，直到碰到對應限位開關。
- `stopMotor()` 用於統一停止推桿，避免慣性持續運轉。

### 6.2 目前版本限制
- 缺少超時保護：若限位開關失效，馬達可能持續運轉。
- 缺少去抖動：限位開關可能因機械抖動造成誤判。
- 缺少手動覆蓋邏輯：故障時不易人工介入。
- `while` 阻塞式寫法不利於後續擴充功能。

為提升安全性與穩定性，建議加入以下功能：
- 動作超時保護（例如 10–20 秒未到位即停止）。

- 手動按鍵控制模式。

### 7.1 升級建議清單
1. **加入超時計時器**：避免限位失效時燒毀馬達。

4. **記錄錯誤碼**：例如展開超時、收回超時、藍牙異常。

## 八、關鍵配置步驟：綁定電視藍牙 MAC

為防止藍牙模組誤連到手機或其他設備，建議透過 AT 指令將 HC-05 鎖定至指定設備位址。

### 8.1 配置流程
1. **獲取電視 MAC 位址**  
   開啟電視藍牙，使用藍牙掃描 App 或串口工具記錄電視的 MAC 位址。  
   例如：`94:E6:63:AB:CD:EF`

2. **進入 HC-05 AT 模式**  
   按住模組按鍵後上電，待 LED 慢閃（約每 2 秒一次）即表示進入 AT 模式。

3. **發送配置指令**  
   ```text
   AT+ROLE=1
   AT+CMODE=0
   AT+BIND=94E6,63,ABCDEF
   ```

4. **重啟模組**  
   完成設定後重新上電，使配置生效。

### 8.2 指令說明
- `AT+ROLE=1`：將 HC-05 設定為主機模式。
- `AT+CMODE=0`：只允許連線至指定地址。
- `AT+BIND=...`：綁定目標藍牙裝置位址。

### 8.3 注意事項
- 不同版本 HC-05 韌體 AT 指令格式可能略有不同。
- MAC 位址格式通常需將冒號 `:` 改為逗號 `,`。
- 若電視藍牙未長時間可被搜尋，可能需重新評估此偵測方案。

## 九、安裝與結構設計建議

### 9.1 機構安裝重點
- 推桿安裝角度需確保全程無卡點與偏擺。
- 抽屜滑軌、平台重心與推桿推力方向需盡量同軸。
- 限位開關位置應可微調，避免提前或延後觸發。

### 9.2 安全建議
- 建議加入保險絲或自恢復保護元件。
- 高電流線材請選擇足夠線徑，避免壓降與發熱。
- 櫃體內需保留散熱空間與維修通道。
- 初次測試務必先降低負載、分步驗證。

## 十、調試流程建議

### 10.1 單元測試順序
1. 單獨測試控制板供電是否正常。
2. 單獨測試 HC-05 狀態腳輸出是否正確。
3. 單獨測試 L298N 是否可正反轉驅動推桿。
4. 單獨測試兩個限位開關是否能正確觸發。
5. 最後再整合藍牙判斷與自動控制流程。

### 10.2 常見故障排查
| 現象 | 可能原因 | 建議處理 |
|---|---|---|
| 藍牙已連線但不動作 | STATE 腳未正確輸出 / 腳位接錯 | 先用萬用表或 LED 測 STATE 腳位變化 |
| 推桿只會單向運轉 | IN1/IN2 邏輯錯誤或接線鬆脫 | 檢查控制腳位與程式定義 |
| 到位後不停機 | 限位開關故障或接法錯誤 | 檢查開關型式（NO/NC）與程式邏輯 |
| Arduino 重啟 | 馬達啟動造成壓降 | 加強供電、分離電源、增加電容 |
