## 🛠️ 專案文檔：基於藍牙監聽的隱藏式激光電視伺服定位伸縮架 (DIY Open-Source Project)

本專案透過微控制器（建議使用 ESP32）主動監聽激光電視的藍牙（Bluetooth）連線狀態。當電視開機並發出藍牙訊號時，系統驅動主平台精準滑出，同步帶動前滑蓋向後收納至固定後蓋下方；當電視關機或藍牙斷開時，主平台回到原點，前滑蓋同步復位關閉，恢復隱藏式整體外觀。

本版本重點從傳統「電動推桿 + 限位停機」升級為「伺服精準定位 + 雙段式上蓋同步聯動」，適用於超窄型激光電視櫃模組、隱藏式展示平台與需要良好外觀整合的智慧家居設備。

---

## 一、專案目標與應用場景

### 1.1 專案目標
- 實現激光電視平台的自動滑出與收納。
- 利用藍牙連線狀態作為設備開關機的間接判斷訊號。
- 使用伺服定位或帶編碼器驅動機構，實現可重複、可調整的精準工作位置。
- 透過雙段式上蓋設計，提升外觀整合度與使用體驗。
- 提供具備基本安全保護、可 DIY 落地的硬體與控制邏輯方案。

### 1.2 適用場景
- 客廳隱藏式激光電視櫃。
- 超窄型激光電視櫃模組。
- 智慧家居設備聯動展示機構。
- 需要平穩伸縮與外觀遮蔽的展示平台或收納模組。

### 1.3 專案特點
- 支援主平台精準控制最終伸出位置。
- 上蓋採用雙段式結構，外觀更接近成品家具模組。
- 前滑蓋與主平台可做同步聯動，動作流暢。
- 支援狀態機控制，便於後續擴充手動控制、遙控、Wi‑Fi 聯動等功能。
- 可依需求選擇「單電機 + 機械聯動」或「雙驅動協同控制」方案。

## 二、設備尺寸、承重與擺放條件

本方案以激光電視 / 投影設備尺寸 **510 × 270 × 144 mm**、重量 **7.9 kg** 為基準進行機構設計。平台、導軌、驅動與上蓋結構需同時滿足擺放空間、承重、安全裕量與散熱避讓等條件。

### 2.1 已知設備條件
- 設備尺寸：**510 × 270 × 144 mm**
- 設備重量：**7.9 kg**

### 2.2 平台尺寸建議
為了滿足設備擺放、止滑、裝配與散熱需求，不建議將平台做成僅剛好容納設備的尺寸。

建議平台有效擺放尺寸至少為：
- **長度 ≥ 560 mm**
- **寬度 ≥ 320 mm**

較穩妥的實作建議：
- **平台面板尺寸：560～600 mm × 320～360 mm**

### 2.3 承重設計建議
設備本體重量雖為 **7.9 kg**，但結構設計不應只按靜態重量選型，還需考慮：
- 平台自重
- 固定支架與防滑墊
- 線材與拖鏈負載
- 啟停過程中的動態慣性
- 偏載、長期磨耗與安全裕量

因此建議：
- **平台、導軌與驅動整體按 ≥ 15 kg 等效負載進行設計**
- 若追求更高耐久性與穩定性，可按 **15～20 kg 級** 結構規格選型

### 2.4 擺放與散熱建議
- 設備四周應預留至少 **20～30 mm** 的安裝與散熱間隙。
- 出風口與進風口方向不得被上蓋、側板或聯動結構遮擋。
- 若櫃體較封閉，建議加開散熱孔或增加輔助風扇。
- 線材、插頭與轉接頭的高度和彎折半徑應納入總高度設計。

### 2.5 結構避讓要求
- 前滑蓋收入固定後蓋下方時，不得侵占設備本體擺放空間。
- 平台運動層、滑蓋收納層與設備空間應盡量分層設計。
- 設備放置位置應盡量靠近平台受力中心，避免前端懸臂過長。
- 平台伸出後仍需具備足夠的抗下沉、抗偏擺與抗扭轉能力。

## 三、上蓋結構設計（雙段式同步滑蓋）

本方案的上蓋不再採用傳統翻蓋，而採用更適合超窄型櫃體的雙段式結構：

- **固定後蓋（Rear Fixed Cover）**：靠牆安裝，不參與運動。
- **前滑蓋（Front Sliding Cover）**：待機時與固定後蓋共同形成完整頂面；開啟時沿導向機構向後滑動，收納至固定後蓋下方。
- **主平台（Projector Platform）**：承載激光電視本體，向前精準滑出到工作位置。

### 3.1 動作邏輯
本版本採用**上蓋打開與平台滑出同步操作**的思路：

- 主平台開始向前運動時，前滑蓋同步向後移動。
- 前滑蓋逐步收入固定後蓋下方，平台逐步向外伸出。
- 收回時，平台向內回位，前滑蓋同步向前復位閉合。

### 3.2 設計優點
- 靠牆側不需翻轉空間。
- 外觀完整，待機狀態更像一體式家具模組。
- 開啟過程更有產品感，視覺上為「平台滑出、蓋板消失」。
- 適合超窄型櫃體與低高度模組設計。

### 3.3 設計注意事項
- 固定後蓋下方需預留前滑蓋的收納高度與導向機構空間。
- 前滑蓋應具備獨立導向結構，避免偏擺或卡滯。
- 前滑蓋關閉末端建議加裝磁吸、定位銷或緩衝膠墊。
- 平台與滑蓋的導向層應盡量分離，不建議共用單一簡化滑槽。
- 應預留線束活動空間，避免與平台或滑蓋干涉。

### 4.1 工作原理概述
1. 激光電視開機後，藍牙進入可連線或已連線狀態。
2. ESP32 偵測到目標藍牙設備狀態變化。
3. 控制板觸發主平台向前移動。
4. 平台移動同時，前滑蓋透過聯動機構同步向後滑入固定後蓋下方。
5. 平台到達目標工作位置後減速停止。
6. 關機時，平台回原點，前滑蓋同步關閉復位。

```text

┌──────────────────────────────────────┐
│ 已斷線且目前平台已展開？             │──是──► [平台向內回位]

```

### 7.1 狀態邏輯
- **藍牙已連線 + 平台未展開** → 平台向工作位置移動，前滑蓋同步打開。
- **藍牙已斷線 + 平台已展開** → 平台回原點，前滑蓋同步關閉。
- **其餘狀態** → 保持目前狀態，避免重複驅動。

### 7.2 同步聯動建議
可依實際結構選擇以下策略：
1. **單電機 + 機械反向聯動（推薦）**：主平台由單一驅動器控制，前滑蓋透過同步帶、連杆或拉索實現天然同步。
2. **雙驅動協同控制**：主平台與前滑蓋各自驅動，但需額外處理同步誤差與故障保護。
3. **分段聯動**：前滑蓋在前段動作期間同步開啟，完全打開後平台繼續前進。

## 八、核心控制原始碼（ESP32 狀態機示意）

```cpp
// 示意用途：伺服定位 + 同步滑蓋架構
// 實際控制方式需依驅動器通訊方式、位置回授方式與機構比例調整

enum SystemState {
  IDLE_CLOSED,
  OPENING_AND_EXTENDING,
  IDLE_OPEN,
  RETRACTING_AND_CLOSING,
  ERROR_STATE
};

SystemState state = IDLE_CLOSED;

bool bluetoothConnected = false;
bool platformAtHome = true;
bool platformAtWork = false;

long homePosition = 0;
long workPosition = 29000;   // 例如 290 mm 對應的編碼器計數
long currentPosition = 0;

void setup() {
  // 初始化 GPIO、藍牙、驅動器、原點開關等
}

void loop() {
  bluetoothConnected = readBluetoothState();
  currentPosition = readPlatformPosition();

  switch (state) {
    case IDLE_CLOSED:
      if (bluetoothConnected) {
        startMoveTo(workPosition);
        state = OPENING_AND_EXTENDING;
      }
      break;

    case OPENING_AND_EXTENDING:
      // 前滑蓋由聯動機構同步動作
      if (isAtPosition(workPosition)) {
        stopPlatform();
        state = IDLE_OPEN;
      }
      break;

    case IDLE_OPEN:
      if (!bluetoothConnected) {
        startMoveTo(homePosition);
        state = RETRACTING_AND_CLOSING;
      }
      break;

    case RETRACTING_AND_CLOSING:
      // 前滑蓋由聯動機構同步復位
      if (isAtPosition(homePosition)) {
        stopPlatform();
        state = IDLE_CLOSED;
      }
      break;

    case ERROR_STATE:
      stopPlatform();
      break;
  }
}

bool readBluetoothState() {
  return false;
}

long readPlatformPosition() {
  return 0;
}

bool isAtPosition(long target) {
  return abs(readPlatformPosition() - target) < 20;
}

void startMoveTo(long targetPosition) {
  // 發送位置命令給主驅動器
}

void stopPlatform() {
  // 停止主平台
}
```

### 8.1 原始碼說明
- 以**狀態機**取代阻塞式 `while`，便於擴充與保護。
- 主平台只需要控制目標位置；前滑蓋由聯動機構同步完成動作。
- `workPosition` 可依櫃體深度、投影需求與機構尺寸調整。
- 建議加入超時、堵轉、越界、回零失敗等錯誤保護。

### 8.2 目前版本建議補強項目
- 動作超時保護。
- 原點校準流程。
- 故障檢測（如平台未到位、滑蓋卡滯）。
- 手動維修模式。
- 斷電重啟後的位置恢復策略。

## 九、關鍵配置步驟：綁定電視藍牙 MAC

為防止誤判或誤連到其他設備，可透過藍牙掃描或綁定策略鎖定目標電視裝置。

### 9.1 配置流程
1. **獲取電視 MAC 位址**  
   開啟電視藍牙，使用藍牙掃描 App 或串口工具記錄電視的 MAC 位址。  
   例如：`94:E6:63:AB:CD:EF`

2. **設定掃描或連線策略**  
   若使用 ESP32 原生藍牙，可依 MAC 位址過濾目標設備。

3. **測試設備狀態變化**  
   驗證電視開機、待機或關機時，藍牙狀態是否能穩定被偵測。

### 9.2 注意事項
- 不同品牌電視的藍牙廣播策略不同，實際測試非常重要。
- 若電視藍牙在待機時仍持續可見，需搭配其他條件做判斷。
- 若需更高可靠性，可考慮 Wi‑Fi、紅外線、CEC 或繼電器訊號作為輔助。

## 十、安裝與結構設計建議

### 10.1 機構安裝重點
- 主平台導軌需確保全程平行，避免偏擺與卡點。
- 前滑蓋導向需輕量、低摩擦，並保證不與主平台干涉。
- 固定後蓋下方必須預留前滑蓋的收納空間。
- 平台重心與驅動力方向應盡量同軸，以提升壽命與穩定性。
- 平台面板尺寸應滿足 **510 × 270 mm** 設備本體擺放需求，並預留散熱與固定邊距。

### 10.2 蓋板設計建議
- 上蓋由兩部分組成：**後蓋固定，前蓋滑入後蓋下方**。
- 前滑蓋打開與平台滑出採**同步操作**。
- 關閉末端建議加入磁吸、阻尼或緩衝結構，避免撞擊異響。
- 可在前滑蓋底部加尼龍滑塊、滾輪或低摩擦條，提升手感與耐久性。

### 10.3 安全建議
- 建議加入保險絲、急停開關或過流保護。
- 高電流線材請選擇足夠線徑，避免壓降與發熱。
- 櫃體內需保留散熱空間與維修通道。
- 初次測試請先空載、低速、短行程驗證。

## 十一、調試流程建議

### 11.1 單元測試順序
1. 單獨測試控制板供電是否正常。
2. 單獨測試藍牙狀態偵測是否正確。
3. 單獨測試主平台驅動是否可精準往返指定位置。
4. 單獨測試前滑蓋聯動是否順暢、無卡滯。
5. 測試平台滑出與前滑蓋同步動作是否一致。
6. 最後再整合藍牙判斷與自動控制流程。

### 11.2 常見故障排查
| 現象 | 可能原因 | 建議處理 |
|---|---|---|
| 藍牙已連線但平台不動作 | 藍牙判斷邏輯錯誤 / GPIO 設定異常 | 先確認 ESP32 是否正確讀取目標狀態 |
| 平台定位不準 | 編碼器參數錯誤 / 傳動打滑 | 重新校準位置對應與傳動張力 |
| 前滑蓋動作不順 | 導向偏擺 / 摩擦過大 / 同步帶過鬆 | 檢查導向平行度與聯動張力 |
| 平台回位正常但蓋板閉合不齊 | 滑蓋末端定位不足 | 增加磁吸、定位銷或可調節擋塊 |
| ESP32 重啟 | 驅動啟停造成壓降干擾 | 加強供電、分離電源、增加濾波電容 |
