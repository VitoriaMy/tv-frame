# 结构装配与安装指南

## 1. 文档目标

本文档用于细化隐藏式激光电视伺服定位伸缩架的结构装配、安装流程、模块分层关系和现场装配注意事项，便于从概念方案进入可落地实施阶段。

---

## 2. 结构模块划分

建议将整机划分为以下 6 个结构子模块：

1. **基础框架模块**
   - 承担全部内部机构安装基准。
   - 提供导轨、电机、外部层板和装饰件安装界面。

2. **主平台模块**
   - 承载投影设备。
   - 与直线导向及驱动机构连接。

3. **上盖模块**
   - 包括固定后盖与前滑盖。
   - 实现待机遮蔽与同步隐藏。

4. **联动传动模块**
   - 用于实现平台滑出与前滑盖反向同步运动。
   - 可选同步带、连杆、拉索或齿条方案。

5. **外部层板与饰面模块**
   - 用于与柜体外观整合。
   - 包括装饰层板、功能层板、前饰板等。

6. **电控与线束模块**
   - 包括 ESP32、驱动器、电源、限位开关、线束固定件等。

---

## 3. 推荐分层关系

建议整体从上到下采用以下分层结构：

1. 外部顶面/装饰可视层
2. 固定后盖 + 前滑盖层
3. 投影设备运动平台层
4. 主导轨与联动传动层
5. 基础框架层
6. 电控、走线与维护层

设计时应避免以下问题：
- 滑盖层与投影设备空间冲突
- 平台底部与联动机构干涉
- 线束侵入导轨与滑盖行程
- 外部层板固定点遮挡维护空间

---

## 4. 建议安装顺序

### 4.1 预装阶段
1. 组装基础框架。
2. 检查框架对角线、平面度与基准面。
3. 安装主导轨与电机底座。
4. 安装平台连接件与联动机构固定座。

### 4.2 主运动机构安装
1. 安装主平台导轨。
2. 安装丝杆模组或同步带直线模组。
3. 安装主平台板。
4. 调整平台运动平行度。
5. 手动测试平台全行程往返。

### 4.3 上盖与滑盖安装
1. 安装固定后盖支撑结构。
2. 安装前滑盖导向件。
3. 安装前滑盖本体。
4. 连接前滑盖联动结构。
5. 检查前滑盖与平台运动同步性。

### 4.4 外部层板与饰面安装
1. 安装前饰板与可视层板。
2. 安装功能层板或辅助承托层。
3. 调整拼缝、齐平度和视觉中心线。
4. 检查安装���是否影响平台与滑盖行程。

### 4.5 电控安装
1. 安装控制器、电源与驱动器。
2. 固定限位开关、传感器与线槽。
3. 进行线束布线和扎带固定。
4. 通电进行单项功能测试。

---

## 5. 关键安装基准建议

### 5.1 框架基准
- 框架底面作为主安装基准面。
- 左右侧边梁作为导轨安装基准。
- 前部中心线作为饰面与平台对称基准。

### 5.2 平台基准
- 平台安装后应与框架中心线对齐。
- 平台运动方向应与导轨严格平行。
- 投影设备摆放位置应尽量靠近承重中心。

### 5.3 滑盖基准
- 前滑盖关闭位置应与固定后盖形成统一顶面。
- 前滑盖关闭缝应作为外观校准重点。
- 打开后的收纳终点应确保完全避让平台运动空间。

---

## 6. 安装公差建议

### 6.1 可视缝隙建议
- 顶盖拼缝建议控制在 **2～4 mm** 视觉均匀范围内。
- 前饰板与侧板拼缝建议控制在 **2～5 mm**。

### 6.2 结构安装公差建议
- 导轨平行度误差尽量控制在小范围内，避免长行程卡滞。
- 层板安装孔建议使用长条孔以便微调。
- 前滑盖导向系统应保留低摩擦运行间隙，但不宜过大以免晃动。

---

## 7. 维护设计建议

建议在结构设计时提前考虑维护便利性：

- 驱动器、电源与控制器应可拆装。
- 前饰板建议可拆卸。
- 外部层板不应完全封死维护通道。
- 重要位置建议采用可重复拆装的螺丝固定，而非不可逆粘接。

## 8. 装配验收检查表

### 8.1 结构验收
- [ ] 框架安装平整无扭曲
- [ ] 导轨固定牢靠且平行
- [ ] 平台往返顺畅无卡滞
- [ ] 前滑盖开合平顺无异响
- [ ] 滑盖关闭后拼缝均匀
- [ ] 外部层板安装牢固且无干涉

### 8.2 电控验收
- [ ] 蓝牙状态可正常检测
- [ ] 平台可准确回零
- [ ] 平台可准确到达工作位
- [ ] 同步联动动作正常
- [ ] 限位与保护逻辑正常

### 8.3 外观验收
- [ ] 顶面齐平
- [ ] 正面整洁无明显外露件
- [ ] 材质、色差、拼缝协调
- [ ] 待机/运行状态观感符合预期
