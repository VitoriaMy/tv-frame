# 接线图与电气设计说明

## 1. 文档目标

本文档用于细化主控、驱动、电源、传感器、限位开关与蓝牙检测方案之间的接线关系，并给出电气设计原则、I/O 分配建议、端子级接线思路、保护建议和调试方法，便于从方案设计进入实际接线与联调阶段。

---

## 2. 系统电气模块划分

建议划分为以下模块：

1. 主控模块：ESP32
2. 驱动模块：伺服驱动器 / 闭环步进驱动器 / 编码器减速电机驱动器
3. 电源模块：12V/24V 主电源 + 5V/3.3V 降压模块
4. 检测模块：蓝牙状态、原点开关、终点保护开关、急停输入
5. 执行与反馈模块：指示灯、蜂鸣器、调试接口
6. 线束模块：动力线、信号线、地线、屏蔽线、拖链线束

---

## 3. 建议接线关系

| 起始设备 | 目标设备 | 类型 | 说明 |
|---|---|---|---|
| ESP32 GPIO | 驱动器控制输入 | 控制线 | 控制平台前进、回位、停止 |
| ESP32 GPIO | 原点开关 | 信号线 | 平台回零检测 |
| ESP32 GPIO | 终点保护开关 | 信号线 | 越界安全保护 |
| ESP32 GPIO | 急停输入 | 信号线 | 异常人工停机 |
| ESP32 蓝牙功能 | 目标电视设备 | 无线 | 检测电视状态 |
| 主电源 | 驱动器 | 动力线 | 提供运动驱动供电 |
| 主电源 | 降压模块 | 电源线 | 为控制系统供电 |
| 降压模块 | ESP32 | 电源线 | 提供稳定低压 |
| ESP32 GPIO | 状态灯 / 蜂鸣器 | 输出线 | 状态与故障提示 |
| 公共 GND | 全部控制端 | 地线 | 确保逻辑参考一致 |

---

## 4. 电源设计建议

### 4.1 电源分层
建议采用以下分层供电方式：

- **动力电源**：驱动器与主电机
- **逻辑电源**：ESP32 与传感器
- **辅助电源**：LED、蜂鸣器、风扇等

### 4.2 供电原则
- 控制电源与动力电源建议分离稳压。
- 所有模块必须共地。
- 驱动器启动瞬间可能产生较大电流波动，应增加滤波与电源裕量。
- 若线束较长，建议考虑压降与导线截面积。
- 电源输入建议预留总开关与保险保护。

### 4.3 推荐电源拓扑
```text
AC 输入
  ↓
主电源（12V / 24V）
  ├─ 驱动器 / 主电机
  ├─ 辅助风扇 / 指示灯（可选）
  └─ DC-DC 降压模块
        ├─ 5V 输出
        └─ ESP32 / 传感器 / 蜂鸣器 / 逻辑输入
```

### 4.4 电源保护建议
- 建议主电源输入端增加保险丝。
- 控制电源建议增加独立保护。
- 电控部分建议增加滤波电容或缓冲电容。
- 若柜体为金属结构，建议预留接地设计。

---

## 5. 限位与原点设计建议

### 5.1 原点开关
- 用于系统上电后的回零校准。
- 应安装在重复精度高、受机械冲击小的位置。
- 建议作为平台起始位置判定基准。

### 5.2 终点保护开关
- 用于越界保护，不建议作为唯一位置控制手段。
- 建议独立于逻辑位置判断存在。
- 可在控制异常时作为最终安全切断条件。

### 5.3 急停输入建议
- 建议预留独立急停输入接口。
- 急停触发后应立即停止运动输出。
- 急停恢复后建议重新回零或进入手动模式。

## 6. 推荐 ESP32 I/O 分配思路

以下为建议性分配，实际可按开发板与驱动器型号调整：

| 功能 | 建议类型 | 说明 |
|---|---|---|
| STEP / PUL | 输出 | 驱动器脉冲控制 |
| DIR | 输出 | 驱动器方向控制 |
| EN / ENABLE | 输出 | 驱动器使能 |
| HOME_SW | 输入 | 原点开关 |
| LIMIT_SW | 输入 | 终点保护开关 |
| ESTOP_IN | 输入 | 急停输入 |
| MODE_KEY | 输入 | 手动模式或维护按键 |
| LED_STATUS | 输出 | 状态指示灯 |
| BUZZER | 输出 | 蜂鸣器 |
| UART_TX / RX | 调试接口 | 串口日志与调试 |

### 6.1 分配原则建议
- 运动控制信号建议集中使用一组 GPIO。
- 开关量输入建议统一使用上拉/下拉逻辑。
- 指示与人机交互接口建议统一放在便于维护的位置。
- 预留至少 2～4 个备用 GPIO 供后续扩展。

---

## 7. 驱动器通用接口定义

若采用闭环驱动器、伺服驱动器或带编码器电机驱动器，建议文档中统一使用以下通用接口定义：

- `PUL` / `STEP`：脉冲控制输入
- `DIR`：方向控制输入
- `ENA`：使能输入
- `ALM`：故障反馈（若驱动器支持）
- `GND`：逻辑地
- `VCC`：逻辑电平参考（如适用）

### 7.1 推荐接线原则
- 先确认驱动器输入逻辑电平是否与 ESP32 兼容。
- 必要时通过光耦隔离板、电平转换模块或中间控制板做隔离与转换。
- 驱动器故障输出若可用，建议接回 ESP32 用于进入 `ERROR_STATE`。

## 8. 端子级接线建议

建议在实际实施时，按“电源端子 / 控制端子 / 开关输入端子 / 调试端子”分类设置端子排。

### 8.1 电源端子建议
- `VIN+`：主电源正极输入
- `VIN-`：主电源负极输入
- `LOGIC_5V`：逻辑电源输出
- `GND`：逻辑地 / 公共地

### 8.2 控制端子建议
- `STEP`
- `DIR`
- `ENA`
- `ALM`（可选）
- `GND`

### 8.3 输入端子建议
- `HOME_SW`
- `LIMIT_SW`
- `ESTOP`
- `MODE_KEY`
- `GND`

### 8.4 调试端子建议
- `UART_TX`
- `UART_RX`
- `5V`
- `GND`

## 9. 布线建议

- 动力线与信号线分开走线。
- 编码器、开关信号线尽量避免与高电流线并行过长。
- 线束应固定在框架侧边或专用线槽中。
- 应预留平台运动与滑盖联动过程中的线束活动余量。
- 必要时使用拖链或柔性护套。
- 线束弯折半径应满足长期往复运动要求。

### 9.1 线束分组建议
- **动力组**：主电源、电机输出
- **控制组**：STEP、DIR、ENA、ALM
- **输入组**：限位、原点、急停、按键
- **调试组**：串口、维护接口、状态灯

---

## 10. 线径与端子建议

### 10.1 建议线径思路
- 控制信号线：可选较细线径，重点保证抗干扰与可靠压接。
- 传感器 / 开关线：建议与控制线同级或略高规格。
- 主电机与驱动动力线：应按实际电流、线长和压降校核。
- 主电源输入线：应按整机最大工作电流留足裕量。

### 10.2 端子建议
- 维护频繁的位置建议采用可插拔端子。
- 高振动或频繁维护区域建议采用带锁紧结构的连接方式。
- 运动区域内接头应尽量减少。

---

## 11. 抗干扰建议

- 电机驱动部分建议加滤波措施。
- 控制器供电端建议加电容缓冲。
- 开关信号建议软件去抖。
- 若采用长线布线，可考虑屏蔽线与单点接地策略。
- 若驱动器干扰明显，可考虑增加隔离模块。

---

## 12. 推荐接口预留

建议预留以下接口，便于调试与扩展：

- USB 调试口
- 电源输入端子
- 驱动器控制接口
- 备用 GPIO 接口
- 手动控制按键接口
- LED / 蜂鸣器接口
- 故障复位接口
- 急停接口
- 维护串口接口

---

## 13. 调试测量点建议

为便于现场排查，建议预留以下测点：

- `TP1`：主电源输出
- `TP2`：5V / 逻辑电源输出
- `TP3`：ESP32 供电输入
- `TP4`：原点开关输入
- `TP5`：终点保护输入
- `TP6`：STEP / DIR 输出
- `TP7`：驱动器使能信号
- `TP8`：公共 GND

### 13.1 测点布置建议
- 测点应尽量靠近关键模块输入端。
- 测点命名应统一，便于维护记录。
- 若后续制作控制板，可将测点印刷在丝印层。

---

## 14. 电气调试顺序

1. 单独确认主电源输出正常。
2. 单独确认降压模块输出稳定。
3. 单独测试 ESP32 上电与程序运行。
4. 单独测试限位开关输入是否正常。
5. 单独测试驱动器控制逻辑。
6. 断开负载测试驱动器动作。
7. 接入主平台机构后低速测试。
8. 完成蓝牙检测与整体联动测试。

### 14.1 推荐分阶段调试方法
#### 第一阶段：静态通电检查
- 核对所有电源输出是否正确。
- 核对共地是否完整。
- 检查是否有异常发热、短路或接反。

#### 第二阶段：输入输出检查
- 检查原点、终点、急停、按键信号。
- 检查 STEP、DIR、ENA 输出逻辑。
- 检查状态灯和蜂鸣器输出。

#### 第三阶段：驱动与空载测试
- 先空载测试驱动器控制。
- 再低速联接机械系统进行往返测试。
- 最后验证蓝牙触发和异常保护。

---

## 15. 实施注意事项总结

- 不要在未确认逻辑电平兼容前直接连接 ESP32 与驱动器。
- 不要将动力线与敏感信号线长距离并行布设。
- 不要忽略共地设计和压降问题。
- 任何自动运行前都应先完成回零和限位测试。
- 建议先完成单模块测试，再进行整机联调。
