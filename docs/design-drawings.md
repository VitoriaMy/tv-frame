# 设计图纸说明

## 1. 文档目标

本文档用于在正式 CAD 图纸形成之前，以结构示意、分层关系、安装界面说明和尺寸逻辑的方式，建立本项目的“图纸级说明文档”，便于后续机械建模、二维出图和制造实施。

---

## 2. 推荐图纸分类

建议后续正式图纸按以下类别整理：

1. 总体布置图
2. 分层结构图
3. 主平台装配图
4. 前滑盖与固定后盖关系图
5. 联动机构示意图
6. 柜体开口与安装界面图
7. 电控布置与走线区图
8. 孔位与安装基准图

---

## 3. 总体结构示意

```text
┌────────────────────────────────────┐
│            外部顶面/饰面层          │
├────────────────────────────────────┤
│      固定后盖      │   前滑盖       │
├────────────────────────────────────┤
│         主平台 / 投影设备层         │
├────────────────────────────────────┤
│    导轨 / 联动机构 / 驱动机构层     │
├────────────────────────────────────┤
│        基础框架 / 电控 / 线束层      │
└────────────────────────────────────┘
```

---

## 4. 顶部结构关系图

```text
待机状态：
┌────────────────────────────────────┐
│      固定后盖      │   前滑盖       │
└────────────────────────────────────┘

开启状态：
┌────────────────────────────────────┐
│      固定后盖                      │
│   （前滑盖收纳于其下方）           │
└────────────────────────────────────┘
        ↑ 主平台向前滑出
```

---

## 5. 平台与滑盖联动示意

```text
平台前进  ─────────►
滑盖后收  ◄─────────

平台回位  ◄─────────
滑盖闭合  ─────────►
```

说明：
- 平台与前滑盖运动方向相反
- 推荐使用同步带形成稳定的反向联动关系

---

## 7. 电控与走线区示意

```text
后部 / 下层区域：
┌────────────────────────────────────┐
│ 电源 │ 驱动器 │ ESP32 │ 端子排 │ 线槽 │
└────────────────────────────────────┘
```

建议：
- 电控集中于下层或后部
- 走线区独立于运动机构主要包络
- 线束应可维护、可替换

---

## 8. 图纸标注建议

建议后续正式图纸统一标注以下内容：

- 总长、总宽、总高
- 平台工作位与回零位
- 固定后盖安装面
- 前滑盖闭合位与收纳位
- 柜体顶面开口尺寸
- 维护开口尺寸
- 安装孔中心距与基准面关系

---

## 9. 出图优先级建议

建议按以下顺序完善正式图纸：

1. 总体尺寸总图
2. 平台与滑盖关系图
3. 联动机构示意图
4. 柜体开口和安装界面图
5. 孔位与安装基准图
6. 电控与走线区布置图
